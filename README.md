# STRC rate controller: replay discretionary resets and stress assumed responses

[![Offline research checks](https://github.com/RahilBhavan/strc-rate-controller/actions/workflows/ci.yml/badge.svg)](https://github.com/RahilBhavan/strc-rate-controller/actions/workflows/ci.yml)

![Only three holdout decisions: hold MAE 0 bp, stated-tier proxy 33.33 bp; no predictive edge established](assets/holdout.svg)

STRC is Strategy's Variable Rate Series A Perpetual Stretch Preferred Stock: a perpetual preferred share whose dividend rate management resets each month, at its discretion, aiming for a price of $99 to $100.

This Python research tool extracts STRC reset history from filings, compares descriptive policies, and simulates assumed BTC/spread shocks. It separates filed reduction constraints from management's discretionary decisions. Financial cutoff: October 21, 2026; market bars end October 20.

## How it works

`strc/history.py` extracts filed rates; `rules.py` separates restrictions from guidance; `features.py` builds price/rate proxies; `fit.py` scores policies; `credit.py` and `sim.py` generate assumed spread and rate paths. All demo inputs come from a frozen, hash-verified local cache.

Terms used in the outputs:

- **Stated-tier proxy** (`framework` policy): the company's published reset guidance read as a rule. Below $95 the rate rises at least 50 bp; $95 to $98.99, 25 bp; $99 to $100.99, no change; $101 and above, a 25 bp cut. The real decision stays discretionary.
- **mNAV**: Strategy's company-defined enterprise value divided by the value of its BTC holdings. The model uses a proxy: Strategy's own mNAV on 2026-10-21, scaled back in time by the MSTR/BTC price ratio.
- **Coverage price** (`b_star`, also written as `coverage_btc_price_usd`): the BTC price at which Strategy's BTC holdings equal its debt plus preferred notional. Below it, the `distance` form has no finite required rate.
- **Spread form**: how the fitted credit spread depends on BTC. `log` uses log(BTC / coverage price); `distance` grows without limit as BTC approaches the coverage price.
- **Assumed slope multiplier**: the fitted spread slope multiplied by 0.5, 1 or 1.5 to show how much the answer depends on that one estimate. It is a sensitivity, not an estimate.
- **$101 simulated ceiling**: the model caps STRC's price at $101, the optional redemption price. Real prices can trade above it.

## Run it

Python 3.12+; tested with Python 3.14.7. Standard library only. From this repository:

```bash
python3 scripts/snapshot.py
python3 scripts/verify_sources.py
python3 -m unittest discover -s tests -v
python3 scripts/run_all.py
python3 scripts/evaluate_policies.py --policy framework
python3 scripts/result_figure.py --check
python3 scripts/readme_table.py --check
```

Observed: **41 tests passed**. No credentials or installation are needed for this offline demo. Generated CSV/JSON are local ignored files. Run `python3 scripts/validate.py` to verify sources, run tests and compare two demo runs. Repeating the demo reproduces seven output hashes. Optional fetch helpers require `SEC_USER_AGENT` with a contact email for EDGAR and may change the sample.

To try your own stress without rewriting any files, pass `--btc-shock` (percent, -95 to 400) and/or `--spread-shock` (basis points, -500 to 2000):

```bash
python3 scripts/run_all.py --btc-shock -40 --spread-shock 200
```

## Scope and limits

- Independent research; no affiliation with Strategy. No investment recommendations or execution.
- The reset is discretionary, never a mandatory price-to-rate formula. The October 28 daily-dividend vote is pending at the cutoff.
- Overnight SOFR substitutes for licensed term SOFR; daily typical-price VWAP and hindsight-scaled mNAV are rough proxies. This is not a contractual compliance certificate or a prospective forecasting validation.
- Fixed capital structure, perpetual pricing and the $101 simulated ceiling are assumptions. No causal identification, redemption guarantee, liquidity or default model.
- Optional fetch helpers are not a rolling update pipeline; the model intentionally loads the frozen snapshot.
- Cached third-party bodies are attributed research inputs, with no blanket redistribution license asserted. See [source rights](docs/sources.md).
